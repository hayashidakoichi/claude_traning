スライド資料を作る 2 つの流れ

原稿は Markdown で 1 つ。配り方に合わせて出口を選ぶ。直すのはいつもテキスト（Markdown／HTML）側

流れ①　Markdown → Marp → PDF文章中心・配布用（Part 2〜5）
流れ②　Markdown → Artifacts → pptxデザインを揃えたい・PowerPoint で渡したい（Part 6）

Markdown 原稿

proposal.md

先頭に marp: true。VS Code で
プレビューし、テーマ CSS で見た目を整える

PDF で配布

「Marp: Export Slide Deck」か marp slides.md
で書き出す。どの PC でも同じ見た目で読める

画像で確認して直す（PNG → Claude に見せる）

Artifacts の HTML スライド

なので「3 枚目を直して」が何度でも効く

ダウンロードする（PDF でも書き出せる）
